## KPI 卡片

### 结构
```
┌─────────────────────┐
│ 指标名称（小字灰色）    │
│ 12,345（大字主色）     │
│ +12.3% 环比（绿色）    │
│ 对比说明（小字灰色）    │
└─────────────────────┘
```

### 数值格式化
使用模板内置的 `window.fmt` 工具：

```javascript
// 在 HTML 中直接使用（需要在 script 标签内）
fmt.num(12345)       // → "12,345"
fmt.cn(12345)        // → "1.2万"
fmt.cn(123456789)    // → "1.2亿"
fmt.pct(0.1234)      // → "12.3%"
fmt.pct(12.34)       // → "12.3%"（已是百分比形式）
fmt.currency(12345)  // → "¥12,345.00"
fmt.date('2024-01-15')     // → "2024-01-15"
fmt.date('2024-01-15','YM') // → "2024-01"
```

### 涨跌颜色
- `.change.up` — 绿色（var(--accent-3)），用于正向变化
- `.change.down` — 红色（#f87171），用于负向变化
- `.change.neutral` — 灰色（var(--text-muted)），用于无变化

**注意**：某些指标"下降"是好事（如成本、退货率），需要根据语义调整颜色方向。

## 图表容器

### 结构
```
┌─────────────────────────────┐
│ 图表标题（14px，加粗）         │
│ 图表副标题（12px，灰色）       │
│ ┌─────────────────────────┐ │
│ │                         │ │
│ │      ECharts 图表        │ │
│ │                         │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

### 布局模式
- `.chart-row.cols-1` — 单列，全宽
- `.chart-row.cols-2` — 双列等分
- `.chart-row.cols-3` — 三列等分
- `.chart-row.ratio-6-4` — 六四分
- `.chart-row.ratio-7-3` — 七三分

### ECharts 初始化模式

每个图表必须用以下模式初始化，确保在 ECharts 加载完成后执行：

```javascript
(function(){
  var chartInstance = null;
  function init(){
    var el = document.getElementById('chart-N');
    if(!el) return;
    chartInstance = echarts.init(el, 'data-deck');
    chartInstance.setOption({
      // 图表配置
    });
    window.registerChart(chartInstance);
  }
  if(window.echarts) init();
  else window.addEventListener('echarts-ready', init);
})();
```

## 数据表格

### 适用场景
- 行数 < 100
- 用户需要看原始数据
- 作为图表的补充（不是替代）

### 样式规范
- 表头：加粗，背景 var(--bg-secondary)，sticky 定位
- 数值列：右对齐，等宽字体
- hover 行高亮：background var(--accent-light)
- 文字不换行（white-space:nowrap），超出滚动

## 洞察文本

### 写作规范
```
✅ "华东区 Q1 销售额 2,340 万，环比增长 15%，占全国 32%"
❌ "华东区销售表现良好"

✅ "3 月退货率 8.2%，为近 6 个月最高，主要由 XX 品类贡献"
❌ "3 月退货率偏高"

✅ "建议：将 XX 品类的库存周转天数从 45 天压缩至 30 天"
❌ "建议优化库存管理"
```

### 结构
- 每条洞察一个要点
- 包含具体数字
- 用对比/排名增强说服力
- 最后一条可以是建议

## 导航控制

### 键盘
- `→` / `空格` — 下一页
- `←` — 上一页
- `Home` — 第一页
- `End` — 最后一页
- `B` — 低功耗模式（关闭动画）

### 滚轮
- 向下滚动 → 下一页
- 向上滚动 → 上一页
- 800ms 防抖

### 触屏
- 左滑 → 下一页
- 右滑 → 上一页
- 60px 阈值

### 导航点
- 底部居中显示
- 当前页高亮（主色 + 放大）
- 点击可跳转
