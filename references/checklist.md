# 质量检查清单（Checklist）

生成 PPT 前通读一遍；生成后逐项自检。

---

## P0 · 一定不能犯的错

### 0-1. 数据完整性
- 所有原始数据列都在输出中有所体现
- 行数与源文件一致（没有静默截断）
- null 值显示为 "—" 或留空，不是 "undefined" 或 "NaN"
- 数字没有被四舍五入到失去意义
- 数据类型检测正确（数值、分类、时间）

### 0-2. 数字格式化
- 金额：¥12,345.67，不是 12345.67
- 百分比：23.5%，不是 0.235
- 大数：1.2万 不是 12000，1.5亿 不是 150000000
- 同一指标的小数位数一致
- 日期格式统一（YYYY-MM-DD 或 YYYY-MM）

### 0-3. 图表类型正确性
- 饼图不超过 8 个分类
- 折线图的 X 轴是连续的（时间/序列），不是分类
- 数值轴从 0 开始（除非有充分理由）
- 每张图表都有标题和 tooltip
- 图表类型与数据特征匹配（见 chart-selection.md）

### 0-4. 单文件可运行
- 浏览器直接打开 index.html 能正常显示
- ECharts 从 CDN 或本地加载成功
- 所有数据内嵌在 HTML 中，不依赖外部文件
- 字体有 fallback 链
- 图表能正常渲染（无空白或错误）

### 0-5. 占位符清理
- `grep '[必填]' index.html` 结果为空
- `grep 'DECK_SLIDES_HERE' index.html` 结果为空
- `<title>` 标签是实际标题
- 所有图表容器 id 已替换（chart-1, chart-2...）

### 0-6. 主题色统一
- 一份 deck 只用一套主题色
- 所有图表的配色来自同一套色板
- 没有硬编码的颜色值（全部走 CSS 变量或 ECharts 主题）
- KPI 卡片的涨跌颜色正确（涨绿跌红）

### 0-7. 低功耗模式
- 按 B 键能切换低功耗模式
- 低功耗模式下动画全部禁用
- 低功耗模式提示文字显示正确
- 退出低功耗模式后功能恢复正常

---

## P1 · 应该做到的

### 1-1. KPI 卡片
- 有 3-5 个关键指标
- 每个都有当前值 + 变化趋势
- 涨跌颜色正确（涨绿跌红）
- 数值格式化正确
- KPI 卡片有左侧 accent 条

### 1-2. 图表交互
- hover 显示 tooltip，内容完整
- 图表能响应窗口 resize
- 翻页后当前页图表自动 resize
- 图表有标题和副标题

### 1-3. 页面节奏
- 不连续 3 页以上同类型
- KPI 在图表之前
- 有洞察/总结页
- 有结束页
- 总页数在 5-15 页之间

### 1-4. 数据洞察
- 洞察有数据支撑（包含具体数字）
- 用对比增强说服力
- 最后有建议/行动项
- 洞察页有左侧 accent 条

### 1-5. 导航功能
- 键盘 ← → 翻页正常
- 滚轮翻页正常（800ms 防抖）
- 触屏滑动翻页正常
- 底部导航点显示正确
- 顶部进度条显示正确
- ESC 键回到第一页

---

## P2 · 做到更好

### 2-1. 视觉细节
- 图表标题简洁明确
- 坐标轴标签清晰
- 颜色区分度足够（色盲友好）
- 数字字号足够大（投屏可读）
- 卡片有 hover 效果

### 2-2. 响应式
- 1920x1080 正常显示
- 1280x720 正常显示
- 768px 以下手机端正常显示
- 480px 以下小手机正常显示
- 图表不溢出容器

### 2-3. 动画效果
- 元素有进入动画（reveal）
- 动画时长合理（0.6s）
- 动画不会影响阅读
- 低功耗模式能禁用动画

---

## P3 · 锦上添花

### 3-1. 打印友好
- `@media print` 样式合理
- 图表在打印时不变形
- 分页正确

### 3-2. 性能
- 1000 行数据加载 < 2s
- 图表渲染 < 500ms
- 翻页切换流畅

### 3.3 代码质量
- 无控制台错误
- 无警告信息
- 代码结构清晰
- 注释适当

## 检查命令

### 快速检查
```bash
# 检查占位符
grep '[必填]' index.html
grep 'DECK_SLIDES_HERE' index.html

# 检查图表数量
grep -c 'id="chart-' index.html

# 检查 KPI 卡片数量
grep -c 'class="kpi-card"' index.html

# 检查 slide 数量
grep -c '<section class="slide' index.html
```

### 完整校验
```bash
node scripts/validate-deck.mjs index.html
```

### 视觉检查
1. 浏览器打开 index.html
2. 逐页检查图表是否正常渲染
3. hover 图表看 tooltip 是否显示正确
4. 检查数字格式（金额有 ¥、百分比有 %、大数有万/亿）
5. 检查 KPI 卡片的涨跌颜色（涨绿跌红）
6. 检查最后一页是否有总结/建议
7. 按 B 键测试低功耗模式
8. 测试键盘翻页、滚轮翻页、触屏翻页
