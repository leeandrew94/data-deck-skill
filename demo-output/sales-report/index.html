KEY INSIGHTS

五大关键发现

  • 总销售额逐月攀升：从1月 ¥726.3万增长至5月 ¥902.7万，累计增幅 24.3%，月均环比增长约 5.6%。
  • 数码品类是增长主引擎：贡献 49.3% 销售额且同比增长率（10.1%）远超其他品类，客单价 ¥390 为最高。
  • 华东区域独大，西南差距显著：华东销售额（¥1,403万）是西南（¥563万）的 2.5 倍，但西南同比增长 27.2% 为各地区最高。
  • 退货率整体可控但服饰偏高：食品退货率最低（平均 1.4%），服饰退货率最高（平均 5.0%），数码居中（3.0%）。
  • 建议关注西南市场与服饰品控：西南增速最快但体量小，加大投入可能带来高回报；服饰退货率需重点分析退因，降低售后成本。
