# Data Deck Skill

[English](README.md) | [中文](#中文)

## 中文

从 CSV/Excel 文件生成数据驱动的 HTML 演示文稿。单文件输出，含交互式 ECharts 图表、KPI 大字报、数据洞察。

**核心流程**：数据分析 → 图表生成 → 结论提炼 → 统一风格输出

## 30 秒开始

```bash
npx skills add https://github.com/YOUR_USERNAME/data-deck-skill --skill data-deck-skill
```

也可以直接把这段话发给有 shell 权限的 AI Agent：

```
帮我安装 data-deck-skill。请把 https://github.com/YOUR_USERNAME/data-deck-skill 克隆到 ~/.claude/skills/data-deck-skill，安装完成后检查 SKILL.md、assets/、references/ 是否存在。
```

安装后直接对 Agent 说：

```
帮我这份销售数据做成周报 PPT，用商务风格。
```

也可以试这些请求：

```
帮我分析一下这份 CSV，做个数据汇报。
这份 Excel 做个科技风格的数据看板。
帮我把这份数据做成可以发给老板的 PPT。
```

## 效果

- 📊 **原生 ECharts 图表** — 不是截图，hover 可看具体数值
- 🎨 **9 种视觉风格** — 商务简洁 / 数据科技 / 极简白 / 暗黑科技 / 暖色商业 / 莫兰迪 / 深海蓝调 / 清新绿意 / 商务汇报
- 📈 **自动数据洞察** — 从数据中提取关键指标和结论
- ⌨️ **键盘翻页** — ← → / 滚轮 / 触屏，像 PPT 一样操作
- 📱 **移动端适配** — 手机端自动切换为垂直滚动，H5 页面体验
- 📄 **单文件 HTML** — 浏览器直接打开，不需要服务器
- 📑 **PDF 导出** — 一键生成 PDF，保留图表渲染效果
- 🔋 **低功耗模式** — 按 B 键切换，禁用动画，适合低性能设备

## 适合 / 不适合

**✅ 合适**：数据周报/月报、销售报表、业务汇报、数据分析演示、发给领导/客户的数据报告

**❌ 不合适**：只需要简单看数据（用 pandas）、极大体量实时查询（用 BI 工具）、多人协作编辑

## 使用流程

1. **数据分析** — 读取 CSV/Excel，自动检测列类型，推断关键指标
2. **选择风格** — 从 9 种预设中选一（不允许自定义颜色）
3. **规划页面** — 封面 → KPI → 图表 → 洞察 → 结束页
4. **生成 HTML** — 拷贝模板、替换主题色、填充内容和图表配置
5. **自检** — 对照 checklist，P0 问题必须全过
6. **预览** — 浏览器直接打开
7. **导出 PDF**（可选）— `bash scripts/export-pdf.sh ./index.html`
